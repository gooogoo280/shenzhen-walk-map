# 走遍深圳

把深圳走透，你就拿到了理解任何城市的钥匙。

这是一个以「深大丽湖校区」为原点的深圳城市行走计划：125 个站点/主题 + 交互式打卡地图 + 每站知识讲解 + 完整方法论手册。灵感来自知乎答主「走遍地图」的十年实践——不花钱、不拼资源，靠持续把脚下的城市走透，建立可以迁移到任何地方的认知方法。

## 在线使用

打开 [https://gooogoo280.github.io/shenzhen-walk-map/](https://gooogoo280.github.io/shenzhen-walk-map/) 即可使用，无需安装。

## 功能

- 134 个站点/主题的打卡清单（含深圳港 11 个港区），按区与主题路线分组
- 每个站点可写笔记，自动保存到浏览器
- 250 余条知识讲解（地理 / 水利 / 工程建筑 / 交通 / 产业供应链 / 人文 / 观察提示）
- 高德地图总览 + 一键定位跳转
- 搜索支持站点名、主题、讲解与笔记内容
- 导出 / 导入备份，导出笔记为 Markdown

## 数据说明

打卡状态和笔记保存在浏览器 localStorage 中，不会上传到任何服务器。请定期使用页面上的「导出备份」保存数据；换设备或清缓存后，用「导入备份」即可恢复。

## 项目结构

- `index.html` — 页面
- `app.js` — 数据与交互逻辑
- `深圳走遍地图.md` — 完整方法论与分区计划手册
- `README.md` — 本说明

## 本地运行

直接双击 `index.html` 即可；或在目录下运行 `python3 -m http.server`，然后访问 `http://localhost:8000`。

## 添加新站点

打开 `app.js`，在 `ITEMS` 数组中按现有格式加一行：

```js
{ g: 'nanshan', t: '人文', n: '站点名称', d: '一句话说明' }
```

可选：在 `EXP` 对象中给该站点名添加讲解条目（键为站点名称）。

`g` 为分区 key：`origin / nanshan / futian / luohu / yantian / baoan / guangming / longhua / longgang / pingshan / dapeng / routes`。
